# Removing declined Bot drafts

A Representative has no delete, and nothing caps how many a Bot drafts. A declined Bot draft stays as a row. The owner decided to leave this as it is (2026-11-03).

## Why this is out of scope

The rate is already limited: each new draft waits on the owner's answer or the 7-day expiry first. No real use has shown that the leftover rows are a problem.

A delete would add a public procedure and remove data, and it would need rules for a Representative with a live Release or an open hand-off. A cap would need a limit with no real use to set it from. Neither is worth that yet.

Look at this again if an owner's list of Representatives gets hard to use because of declined drafts.
