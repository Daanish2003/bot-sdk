ai-chat Chat SDK · Reference · from Lesson 1

Package map

One Host, four SDK parts, four Host packages. Imports point down.

The ruleAn import is allowed when it goes down the map. client or ui may reach up to server only with import type. Nothing imports the Host, and core/ imports no @ai-chat/* package.

The four SDK parts

Part Owns Imports Entry point Who edits it
ui/ React components: chat view, shell, pages, settings client, shared, @/components/ui/*; server (type only) @ai-chat/chat-sdk/ui The Host (copied once)
core/client createChatClient, ChatProvider, hooks in client/react shared; server (type only) @ai-chat/chat-sdk/client Nobody (replaced on copy)
core/server createChat, the handler, handleChat, the Run, routers, chat tables shared @ai-chat/chat-sdk/server Nobody (replaced on copy)
core/shared Message parts, Models, Sources, error codes npm only (zod, @tanstack/ai) (through the others) Nobody (replaced on copy)

What the Host gives

Thing In apps/web
Who the user is: getUser(request) → { id } | null src/services.ts (asks Better Auth)
One catch-all route → chat.handler(request) src/routes/api/chat/$.ts
Postgres: databaseUrl (SDK tables in schema chat) src/services.ts
Client wiring: ChatProvider with a router adapter src/lib/chat-provider.tsx

Review checks

  • Does a file in core/ import the Host, @/…, or an @ai-chat/* package?
  • Does client or ui import a value from server? Only import type is allowed.
  • Does shared import server, client or anything with Node or Postgres?
  • Does a Host route hold logic that belongs in core/server?
  • Is a fix made in a Host's copied core/? It belongs in packages/chat-sdk.
